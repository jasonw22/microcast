StatusAnalytics

Hyperlocal forecasts for configured places and routes. Each model corrects HRRR, NOAA's hourly 3 km forecast, using what nearby stations have actually measured. Every score below compares it against raw HRRR on the same forecasts.

Phase 1 gate

The residual model must beat raw HRRR at 1–6 h leads, with a 95% confidence interval that excludes zero. Skill = 1 − CRPS(model) / CRPS(raw HRRR); higher is better.

Leaderboard

Rolling monthly backtests: each month is forecast by models trained only on earlier months. Pooled over the stations. CRPS is the error of the whole forecast distribution, in the target's units. 80% cover should be close to 80%.

Performance over time

Skill against raw HRRR for each test month. The gray line at zero is raw HRRR itself.
